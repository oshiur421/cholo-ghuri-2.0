# Cholo Ghuri — Web (Vercel)

Cholo Ghuri — Biker Convoy & Highway Radar web app. Static site, kono build step nai.

## Deploy (Vercel)

1. Ei repo ta GitHub e push koro.
2. Vercel e giye **Add New > Project**, repo ta select koro.
3. Framework Preset: **Other**. Build Command khali rakho, Output Directory khali rakho.
4. **Deploy** dao — live URL peye jaba.

## Local test

```bash
python3 -m http.server 8000
# tarpor http://localhost:8000 khulo
```

Internet lagbe: Mapbox map, Supabase realtime, Tailwind/Leaflet CDN online chara cholbe na.
